# My Dotfiles 🖥️

Hyprland setup with matugen theming, waybar, swaync, rofi, wlogout, alacritty and fish. Feel free to copy :)

# Install 📦
1. Clone the repository:
   ```
   git clone https://github.com/idea90/my-new-dotfiles.git
   ```
2. Change into the dotfiles directory:
   ```
   cd my-new-dotfiles/
   ```
3. Install dependencies (Arch, uses `yay`):
   ```
   ./install-deps.sh
   ```
4. Symlink configs into `~/.config` (existing dirs are backed up as `*.bak`):
   ```
   ./link.sh
   ```
5. Put wallpapers in `~/wallpapers`. `Super+W` opens the wallpaper/theme picker.

Optional: `./setup-git.sh` sets your global git name/email.
